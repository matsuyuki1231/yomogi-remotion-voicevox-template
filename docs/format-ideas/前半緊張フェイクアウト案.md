# 前半で緊張 → 後半で落ち着かせて生活サーバー宣伝：フォーマット案集

「前半で茶番・緊張感を持たせるコンテンツ → 後半でトーンダウンして宣伝」という
勝ちパターンの新フォーマット候補。宣伝先はいずれも「よもぎサーバーの生活サーバー」。

---

## ★採用（3作目・現行）：裁判・尋問型

「被告人はマイクラの中で会社を経営していると証言」で開廷し、検察官(めたん)が
「そんなわけがない＝ホラ吹きの疑い」で起訴する法廷茶番。被告人(ずんだもん)が証拠映像を
提出するたび「事実」と認定され、常設の《有罪の心証》メーターが 98%→0% へ削れていく。
最終尋問「参加費はいくら？」→「0円」で判決は無罪。法廷トーンを解除して正体＝生活サーバーを
明かし、穏やかな機能紹介＋検索CTAへ着地する。
→ 実装済み（`config/script.living-server-court.yaml` / `src/components/CourtHud.tsx` / タグ `format-court-v1`）

## ★採用（2作目）：緊急速報・報道型

「【速報】マイクラ内に謎の巨大都市が出現」とフェイクニュースで緊張。現場中継風に映像を
映し、専門家(めたん)が深刻に解説。実は住民全員がプレイヤーの生活サーバーだったと判明し、
速報トーンを落として穏やかに機能紹介＋検索CTAへ転換する。ニュースUIで演出。
→ 実装済み（`config/script.yaml` / `src/components/NewsHud.tsx` / タグ `format-news-v1`）

## ★採用（1作目）：怪しい勧誘・詐欺疑い型

めたんが「無料で家がもらえて稼げる場所がある」とずんだもんを勧誘。ずんだもんは
「絶対詐欺なのだ！」と全力で警戒し問い詰める茶番で緊張を作る。後半、疑いを一つずつ
潰していくと全部本当＝生活サーバーの機能だったと判明し、安心トーンで宣伝へ着地する。
→ 実装済み（`config/archive/script.living-server-scam.yaml` / タグ `format-scam-v1`）

## ホラー肝試し型

「夜中に絶対入っちゃいけないワールドがある、入った人は戻ってこない」と二人が肝試し。
暗い映像・鼓動SE・赤テロップで恐怖を煽り恐る恐る潜入。踏み込むと超平和な街でオチ、
「戻れないんじゃなく居心地が良すぎて帰らないだけ」と回収して安心トーンで宣伝。

## 事件・行方不明ミステリー型

「ずんだもんが3日前から行方不明」とめたんが捜索する緊迫のミステリー。手がかりを辿ると
生活サーバーで釣り・家づくりに没頭していただけと判明。緊張を解いて「面白すぎて連絡を
忘れる場所」として穏やかに紹介し、検索CTAでループさせる。
